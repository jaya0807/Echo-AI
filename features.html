Explore ECHO AI

Four signals One intelligent assessment workflow

ECHO AI combines wearable sensing, movement analysis, speech analysis, and handwriting assessment to create a multimodal screening experience

Four Core Assessment Features

01 — Tremor Analysis

Wristband-based motion sensing

  • Captures hand movement using an IMU
  • Measures tremor-related motion patterns
  • Provides quantitative tremor features
  • Supports frequency-based analysis

02 — Gait Analysis

Movement-based assessment

  • Captures walking-related movement
  • Analyzes gait characteristics
  • Uses movement patterns as an additional assessment signal
  • Complements tremor analysis

03 — Speech Analysis

Voice-based assessment

  • Captures speech samples through a microphone
  • Extracts measurable speech characteristics
  • Uses speech patterns as another assessment modality

04 — Handwriting Analysis

Visual handwriting assessment

  • Captures handwriting through a camera/webcam
  • Examines handwriting-related movement patterns
  • Adds another measurable signal to the overall assessment
